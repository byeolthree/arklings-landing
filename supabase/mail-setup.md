# 메일 설정 순서 (아키텍터용) — 네이버 메일 계정으로 모두 보냅니다

가입 확인 메일, 신청자 접수 확인 메일, 새 협업 신청 알림 메일 모두 **아키텍터의 기존 네이버 메일 계정**으로 보냅니다(새 메일 계정은 만들지 않습니다).
알림 메일도 같은 네이버 메일함으로 받습니다. 값은 채팅·GitHub에 붙이지 말고, 아래 「넣는 곳」에만 입력해 주세요.

> **확인하지 못한 값이 많습니다.** 이 작업 환경에서는 네이버 서버와 도움말 페이지에 접속할 수 없어서(네트워크 제한),
> 아래 값은 일반적으로 알려진 설정을 적은 것입니다. 「확인 못 함」 표시는 실제 네이버 화면에서 한 번 확인해 주세요.

## 보낼 때 쓰는 값 (환경변수 이름 → 넣을 값)

| 이름 | 넣을 값 | 상태 |
|---|---|---|
| `MAIL_SMTP_HOST` | `smtp.naver.com` | 확인 못 함 |
| `MAIL_SMTP_PORT` | `465` (처음부터 암호화 연결, SSL). 안 되면 `587` | 확인 못 함 |
| `MAIL_SMTP_USER` | 네이버 아이디 (`@naver.com`을 뺀 아이디인지, 전체 주소인지는 확인 못 함 — 안 되면 다른 쪽으로 바꿔 보기) | 확인 못 함 |
| `MAIL_SMTP_PASS` | 네이버 **애플리케이션 비밀번호** (2단계 인증을 쓰는 경우). 쓰지 않으면 로그인 비밀번호가 필요하지만 권장하지 않음 | 확인 못 함 |
| `MAIL_FROM` | 같은 네이버 메일 주소 (예: `내아이디@naver.com`). 보내는 주소는 로그인한 계정 주소와 같아야 보내지는 것으로 알려져 있음 | 확인 못 함 |
| `ADMIN_NOTIFY_EMAIL` | 새 협업 신청 알림을 받을 주소. 같은 네이버 주소 | — |

코드는 포트가 `465`이면 처음부터 암호화 연결을, 그 밖의 포트는 연결 뒤 암호화로 올리는 방식을 씁니다. 보내는 이름은 「아클링스」로 고정입니다.

## 순서

1. **네이버 메일에서 SMTP 켜기** — 네이버 메일 → 환경설정 → POP3/IMAP 설정에서 SMTP(외부 프로그램에서 메일 보내기)를 **사용함**으로 바꿉니다. (메뉴 이름·위치는 확인 못 함)
2. **애플리케이션 비밀번호 만들기** — 네이버 계정의 보안 설정에서 2단계 인증을 켜고, 「애플리케이션 비밀번호」를 만들어 복사해 둡니다. (메뉴 이름·위치는 확인 못 함)
3. **Supabase에 입력 (가입 확인 메일·카카오 이메일 확인 메일용)** — Supabase 화면 → Authentication → SMTP Settings:
   - 사용자 지정 SMTP 켜기
   - 보내는 주소: 위 `MAIL_FROM`과 같은 네이버 주소 / 보내는 이름: `아클링스`
   - Host: `smtp.naver.com` / Port: `465` / Username: 위 `MAIL_SMTP_USER` / Password: 위 `MAIL_SMTP_PASS`
   - (Supabase가 465 포트를 받아 주는지, 시간당 발송 한도가 얼마인지는 확인 못 함 — 화면에 보이는 값을 확인해 주세요)
4. **이메일 문구 바꾸기** — Authentication → Emails(Email Templates)에 `supabase/email-templates.md`의 문구를 붙여 넣습니다.
5. **로컬 시험용 `.env.local`** (컴퓨터 폴더 맨 위, GitHub에 올라가지 않음) — 위 표의 6개 + `SUPABASE_SERVICE_ROLE_KEY` + (선택) `RATE_LIMIT_SALT`.
6. **Vercel** — 프로젝트 → Settings → Environment Variables에 같은 값을 넣습니다(Production, Preview 모두). 값을 바꾼 뒤에는 다시 배포해야 적용됩니다.
7. **SQL 실행은 배포 뒤에** — 새 코드를 먼저 배포하고 환경변수가 들어간 것을 확인한 다음 `0003_collab_recipient_rls.sql`을 실행합니다. (먼저 실행하면 아직 옛 코드인 사이트에서 신청 접수와 목록이 멈춥니다.)
8. **시험** — 가짜 이메일이 아니라 본인이 받을 수 있는 주소로 ① 가입 확인 메일이 오는지 ② 협업 신청을 보내 알림 메일(네이버 메일함)과 접수 확인 메일(신청 때 적은 이메일)이 오는지 확인해 주세요.

## 알아 둘 점 (확인 못 함)

- **스팸함:** 도메인 없이 네이버 계정에서 나가는 메일이라 받는 쪽에서 스팸함으로 분류될 수 있습니다.
- **같은 주소로 보내고 받는 경우:** 알림을 받는 주소와 보내는 주소가 같은 네이버 계정이면, 네이버가 받은메일함이 아니라 「내게쓴메일함」이나 보낸메일함에만 두는지는 확인하지 못했습니다. 알림이 안 보이면 이 메일함도 확인해 주세요.
- **발송 한도·보내는 주소 제한:** 네이버의 하루 발송 한도 수치와 보내는 주소에 대한 제한은 확인하지 못했습니다.
- **도메인을 사게 되면:** 위 환경변수 값만 도메인 메일 발송 서비스의 값으로 바꾸면 됩니다. 코드는 그대로입니다.

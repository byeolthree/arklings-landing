# 구글·카카오 로그인 설정 확인표 (미션7 단계 4)

코드는 아래 설정이 되어 있다는 전제로 만들었습니다. 이 작업 환경에서는 진짜 Supabase·구글·카카오에 접속할 수 없어서
**아래 항목은 가짜 서버로만 시험했고, 진짜 서비스에서 한 번씩 확인이 필요합니다.**

## Supabase 화면 (아키텍터)

1. **Authentication → URL Configuration**
   - Site URL: 배포 주소. Redirect URLs에 `http://localhost:3000/**`, `https://<배포주소>/**` (이미 있으면 그대로).
   - 구글·카카오 로그인이 끝나고 돌아오는 곳은 `https://<배포주소>/auth/callback` 입니다(위 `/**`에 포함).
2. **Providers → Google, Kakao**: 켜짐(완료). 카카오는 **Allow users without an email** 켜짐(완료).
3. **Allow manual linking(수동 연결 허용): 반드시 켜기.**
   - 켜야 하는 곳: Authentication → Sign In / Providers 안의 설정(메뉴 이름은 화면에서 확인하지 못함).
   - 이 설정이 꺼져 있으면 ① 마이페이지의 「구글/카카오 연결·해제」 ② 카카오 이어주기 승인이 「준비 중」 안내로 끝납니다(오류 화면은 아니고, 아무것도 지워지지 않습니다).
4. **같은 이메일 자동 연결**: Supabase 기본 동작(이메일 소유가 확인된 구글 이메일은 같은 이메일 계정에 자동으로 이어짐)에 기댑니다. 설정에서 끄지 마세요.
5. **Email Templates**: `supabase/email-templates.md`의 1~4번(가입 확인, 이메일 변경, 로그인 링크(Magic Link), 비밀번호 재설정)을 붙여 넣기.
6. **SMTP**: 기존 네이버 SMTP 설정(`supabase/mail-setup.md`). 메일이 5종 더 늘어나므로(이메일 확인·로그인 링크·비밀번호) 시간당 발송 한도를 확인하세요.

## 카카오 개발자 콘솔 (아키텍터, 완료했다고 하셨지만 확인 항목)

- 동의항목은 닉네임·프로필 사진만. 코드는 카카오에 `profile_nickname profile_image` 권한만 요청합니다(이메일 권한을 요청하면 카카오가 거부해서).
- Redirect URI: `https://<프로젝트>.supabase.co/auth/v1/callback`.

## 진짜 서비스에서 한 번씩 해 볼 것 (확인하지 못한 동작)

| 확인 | 기대 결과 |
|---|---|
| 구글로 새 가입 | 마이페이지로 이동, 공개 이름이 구글 이름 |
| 이메일 가입 계정과 같은 이메일의 구글 로그인 | 같은 계정으로 이어짐(계정이 둘로 안 나뉨) |
| 카카오 첫 로그인 | 「이메일을 알려 주세요」 화면 → 메일 링크 → 확인 뒤 정상 사용 |
| 카카오에서 이미 쓰는 이메일 입력 | 똑같은 「확인 메일을 보냈어요」 → 링크 → 승인 화면 → 이어짐 |
| 카카오 이메일 입력 메일(이메일 변경 템플릿) | 링크가 `/auth/confirm?...&type=email_change`로 들어옴. **카카오 계정처럼 이메일이 처음 붙는 경우에 메일이 한 통만 오는지** 확인(Supabase의 「Secure email change」 설정에 따라 다를 수 있음) |
| Supabase 설정 「Confirm email」(Authentication → Sign In / Providers → Email) | **켜져 있어야 한다.** 꺼져 있으면 이메일로 가입한 사람이 확인 메일을 누르기 전에 로그인된다. (시험용 Supabase에서 켠 상태로 「확인 전 로그인 거절·메일 링크 뒤 이메일이 붙음」을 확인했다) |
| 이메일을 입력하지 않은 카카오 계정으로 `/planner`·`/mypage`·`/collab` 열기 | 모두 「이메일 확인」 화면으로 감. 이메일 확인 전에는 기획안 저장·공개 이름 변경·신청 보기가 안 됨 |
| 마이페이지 방법 추가·해제 | 수동 연결을 켠 뒤 동작 |
| 구글·카카오 동의 화면에서 「취소」 | 「로그인을 취소했어요」 안내 + 다음 버튼 |

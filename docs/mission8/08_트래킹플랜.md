## 사용자 속성

코드에 실제로 있는 것만입니다.

| 속성 | 의미 | 규칙 |
|---|---|---|
| Amplitude 사용자 ID | 로그인한 사람의 내부 번호 | 로그인하면 설정, 아니면 익명 |
| `signup_method` | 가입·로그인 방식 | 값이 있을 때만 |
| `initial_utm_source` | 처음 들어온 채널 | 한 번 정해지면 안 바뀜 |
| `initial_utm_medium` | 처음 들어온 매체 | 같음 |
| `initial_utm_campaign` | 처음 들어온 캠페인 | 같음 |
| `initial_utm_content` | 처음 들어온 소재 | 같음 |

로그인 여부는 별도 이벤트 속성이 아닙니다. Amplitude 사용자 ID가 있으면 로그인, 없으면 익명입니다. 오늘 라이브 이벤트에서 `home_view`와 `planner_cta_click`은 익명, 저장 이후 이벤트는 로그인 사용자 ID로 보였습니다.

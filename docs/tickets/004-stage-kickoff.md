# 티켓 004 — 단계 시작 장치

상태: 기획 승인 (2026-11-17)
상태: 완료 (2026-11-17)

## 왜
미션8(GA4·Amplitude)을 시작하면서 기획 세션을 건너뛰고 Claude Code에 바로 일을 넣으려 했다.
새 세션·새 단계·다른 단락을 시작할 때 워크플로우 설계(기획 → 티켓 → 구현)를 거치게 하는 장치가 없었다.

## 바꾼 것
| 위치 | 내용 |
|---|---|
| `.claude/hooks/session-start.sh` | 세션을 열면 "구현 세션"이라는 역할, 임무, `상태: 기획 승인`이 있고 `상태: 완료`가 없는 티켓을 보여 준다. 그런 티켓이 없으면 지시를 적고 "기획 세션에서 티켓을 먼저 만들어 달라"고 보고한 뒤 기다리게 한다 |
| `.claude/mission.md` | 임무를 미션8로 바꿨다 |
| 계정 스킬 `stage-kickoff` | 기획 쪽 장치. 아키텍터가 저장 카드로 등록 |
| 프로젝트 문서 `claude/단계표.md` | 단계마다 기획 세션·티켓·구현 세션·상태를 한 줄씩 적는다 |

## 티켓 표기
티켓 맨 위 둘째 줄에 `상태: 기획 승인 (날짜)`를 적는다. 다 끝나면 `상태: 완료 (날짜)`를 더한다.

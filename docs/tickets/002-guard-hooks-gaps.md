- 구현 모델: Sonnet 5.5
- 가지: `chore/guard-hooks-gaps` (dev에서 갈라서 PR을 dev로 연다)

## 목적

티켓 001의 훅이 놓치는 두 경우를 막는다.

## 만들 것

| 번호 | 파일 | 내용 |
|---|---|---|
| 1 | `.claude/hooks/scope-lock.py` | Bash 명령이 저장소 안 파일에 직접 쓰는 경우도 범위 잠금을 건다. 대상: `>`·`>>` 리디렉션, `tee`, `cp`·`mv`의 도착 경로. 도착 파일이 저장소 안이고 `approved`가 없거나 `scope.json`의 `files`에 없으면 거부한다. 저장소 밖 경로와 `/dev/null`은 통과시킨다. 거부 문구는 기존 범위 잠금 문구와 같게 쓴다 |
| 2 | `.claude/hooks/evidence.py` | push한 커밋이 여러 개면 모두의 바뀐 파일을 본다. 기준은 push 직전 원격 가지 위치부터 HEAD까지다. 원격 위치를 알 수 없으면 `origin/dev`와의 갈림점부터 HEAD까지 본다 |

## 건드리지 않을 것

- 위 두 파일의 나머지 동작, 그 밖의 훅·설정 파일
- 화면·서버·DB 코드 전부(`app/`, `components/`, `lib/`, `supabase/`, `public/`)
